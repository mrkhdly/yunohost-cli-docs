# App - Actions

```
yunohost app action {list,run} ... [-h]
```

## Actions

| Command | Description | Options |
|---------|-------------|---------|
| `list <app>` | List available app actions | — |
| `run <app> <action>` | Run an app action | `-a ARGS` (serialized arguments) |
