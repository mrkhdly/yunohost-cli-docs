# DynDNS (Deprecated)

```
yunohost dyndns {subscribe,update} ... [-h]
```

> ⚠️ **Deprecated** — use [`yunohost domain dyndns`](07-domain-dyndns.md) instead.

## Actions

| Command | Description | Options |
|---------|-------------|---------|
| `subscribe` | Subscribe to DynDNS | `-d DOMAIN` (deprecated), `-p RECOVERY_PASSWORD` |
| `update` | Update IP on DynDNS platform | `-d DOMAIN`, `-f` (force, debug), `-D` (dry-run) |
