# Domain - Config

```
yunohost domain config {get,set} ... [-h]
```

## Actions

| Command | Description | Options |
|---------|-------------|---------|
| `get <domain> [key]` | Display domain configuration | `-f` (full details), `-e` (export key/values) |
| `set <domain> [key]` | Apply new configuration | `-v VALUE`, `-a ARGS` (serialized) |
