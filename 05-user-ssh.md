# User - SSH

```
yunohost user ssh {list-keys,add-key,remove-key} ... [-h]
```

## Actions

| Command | Description | Options |
|---------|-------------|---------|
| `list-keys <username>` | Show authorized SSH keys | — |
| `add-key <username> <key>` | Add an authorized key | `-c COMMENT` |
| `remove-key <username> <key>` | Remove an authorized key | — |
