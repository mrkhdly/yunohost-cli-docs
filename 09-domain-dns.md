# Domain - DNS

```
yunohost domain dns {suggest,push} ... [-h]
```

## Actions

| Command | Description | Options |
|---------|-------------|---------|
| `suggest <domain>` | Generate sample DNS configuration | — |
| `push <domain>` | Push DNS records to registrar | `-d` (dry-run), `--force` (update/remove manual changes), `--purge` (delete all) |
