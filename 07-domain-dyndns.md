# Domain - DynDNS

```
yunohost domain dyndns {subscribe,unsubscribe,set-recovery-password} ... [-h]
```

> This is the non-deprecated version. See [deprecated dyndns](18-dyndns-deprecated.md).

## Actions

| Command | Description | Options |
|---------|-------------|---------|
| `subscribe <domain>` | Subscribe to DynDNS service | `-p RECOVERY_PASSWORD` |
| `unsubscribe <domain>` | Unsubscribe from DynDNS service | `-p RECOVERY_PASSWORD` |
| `set-recovery-password <domain>` | Set recovery password | `-p RECOVERY_PASSWORD` |
