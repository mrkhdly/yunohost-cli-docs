# App - Config

```
yunohost app config {get,set} ... [-h]
```

## Actions

| Command | Description | Options |
|---------|-------------|---------|
| `get <app> [key]` | Display app configuration | `-f` (full), `-e` (export), `--core` (API only) |
| `set <app> [key]` | Apply new configuration | `-v VALUE`, `-a ARGS`, `-f ARGS_FILE` (YAML/JSON), `--core` |
