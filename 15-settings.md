# Settings

```
yunohost settings {list,get,set,reset-all,reset} ... [-h]
```

## Actions

| Command | Description | Options |
|---------|-------------|---------|
| `list` | List all settings | `-f` (full) |
| `get <key>` | Get a setting value | `-f` (full), `-e` (export) |
| `set [key]` | Set a setting value | `-v VALUE`, `-a ARGS` |
| `reset-all` | Reset all to defaults | — |
| `reset <key>` | Reset one setting to default | — |
