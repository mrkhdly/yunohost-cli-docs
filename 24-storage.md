# Storage

```
yunohost storage disk {list,info} ... [-h]
```

## Actions

| Command | Description | Options |
|---------|-------------|---------|
| `list` | List attached hard-drives | `-H` (human-readable), `--human-readable-size`, `-i` (with info) |
| `info` | Get hard-drive information | `-H` (human-readable), `--human-readable-size` |
